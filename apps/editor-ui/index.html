Project explorer

Recover project

Open an existing folder whose game.json is missing. Use a workspace-relative path with / separators, or leave it blank for the workspace root. No files are written until you save a repair.

New project

Create a game with a start screen and an adventure scene.

Use letters, digits, underscores or hyphens. A new folder will be created in the workspace.

Duplicate project

Copy the open project's saved files and assets into a new folder, then open the copy. The copy has its own game ID. Unsaved edits are not included.

Rename project

Change the title or folder name. The game ID and preview saves are kept.

Deleted projects

Deleted projects stay in workspace trash. Restore to the original folder or another unused folder.
